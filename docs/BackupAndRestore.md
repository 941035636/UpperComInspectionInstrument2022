# V1.0.0 数据备份与恢复

## 备份范围

必须备份：`%UserProfile%\Documents\温湿度校准数据`。

建议同时备份：`%LocalAppData%\IndustrialEquipmentCalibration`，其中包含账户、系统设置和当前任务。`remembered-login.json` 只对原电脑的原 Windows 用户有效，跨电脑恢复时应排除。

## 标准备份步骤

1. 停止实时测量和正式采样，正常退出软件。
2. 确认任务管理器中没有 `UpperComInspectionInstrument2022.exe`。
3. 把两个目录分别复制或压缩到有日期和操作者标识的受控位置。
4. 对备份压缩包计算 SHA-256，并在备份记录中登记文件名、大小、哈希、时间和操作者。
5. 抽查压缩包能否打开，并确认至少包含 `作业摘要.csv`、`任务信息.csv`、`正式采样.csv`、`校准结果.csv` 和 `报告` 目录。

不要只备份 Excel/Word。任务、正式采样、结果 CSV 才是重复生成报告的基础归档。

## 恢复步骤

1. 退出软件，把当前数据目录重命名为带时间的临时保留副本。
2. 将备份解压到原路径，保持目录层级和文件名不变。
3. 跨电脑恢复时，复制 `users.json` 和 `system-settings.json` 前应确认客户允许迁移本机账户；不要复制 `remembered-login.json`。
4. 启动软件，检查历史记录数量和状态，打开至少一条 JJF 1101 与一条 JJF 1376 作业。
5. 从冻结 CSV 重新生成一次 Excel 和 Word，核对任务编号、设定值、样本数及结果。
6. 验证完成前不要删除步骤 1 的临时副本。

## 异常处理

- 单个 CSV 人工修改损坏：保留原文件，使用最近备份替换；不要用空白文件覆盖。
- 账户文件损坏或忘记密码：可在登录页重新注册；不会删除业务目录。
- 记住密码无法解密：删除 `remembered-login.json` 后手工输入密码，或按受控单机策略重新注册。
- 恢复后历史记录为空：核对路径是否为当前 Windows 用户的“文档”目录，以及作业文件夹内是否有 `作业摘要.csv`。
