# V1.0.0 软件交付说明

## 已覆盖

- JJF 1101-2019 环境试验设备温度、温湿度单工况校准流程；
- JJF 1376-2012 箱式电阻炉单工况校准流程；
- 巡检仪 Modbus RTU 完整温度块和湿度块读取、动态测点矩阵、趋势和实时 CSV；
- 稳定确认、正式样本、结果公式、不确定度最终量值及本地 CSV 固化；
- Excel 原始记录和 Word 校准报告；内部 CSV 自动固化，PDF 兼容服务不进入普通用户流程；
- 单串口采集互斥、有限退避、异常退出恢复、运行日志和操作记录。
- 首次运行本地账户注册、PBKDF2-SHA256 密码摘要验证、忘记密码直接重新注册、Windows 用户级加密记住密码、启动登录拦截、当前用户显示和注销。
- 当前用户安装、同版本覆盖升级、Windows 卸载登记、桌面及开始菜单快捷方式；卸载保留业务数据和账户配置。
- 一键 Release 回归、自包含便携包、NSIS 安装包、SHA-256 校验值、用户手册、数据字典、备份恢复和验收清单。

## 不属于本次开发完成范围的现场验收项

- 真实巡检仪 8 h 连续运行、拔插、断电、端口竞争和错误从站地址测试；
- Word 在客户办公软件和打印机上的逐页验收；

上述两项按委托方要求不计入本次开发完成条件，应在客户现场验收记录中单独填写。JJF 1101、JJF 1376 的业务结论仍需由有资质的校准人员复核签发，软件不会替代人员授权。

## 已知交付边界

- 当前安装程序没有客户受信任的代码签名证书，Windows 可能提示“未知发布者”。
- 登录为单机便捷访问控制；“忘记密码”允许直接重新注册并替换账户，不适用于多人共用且需要强身份审计的环境。
- 一次任务对应一个校准工况；规范未要求的多工况编排不在 V1.0.0 范围内。
- 没有录入客户技术允差时，系统只计算并报告量值，不自动给出“合格/不合格”结论。
