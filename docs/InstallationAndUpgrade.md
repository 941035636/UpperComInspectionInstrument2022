# V1.0.0 安装、升级、卸载与回退

## 安装

1. 确认系统为 64 位 Windows 10/11，安装 USB 转串口驱动。
2. 校验安装包 SHA-256 与随附 `checksums.csv` 一致。
3. 退出旧版程序和所有串口调试工具。
4. 运行 `UpperComInspectionInstrument2022-Setup-1.0.0.exe`，按向导完成安装。
5. 默认安装目录为 `%LocalAppData%\Programs\UpperComInspectionInstrument2022`，不要求管理员权限。
6. 从桌面或开始菜单启动，完成本地账户注册和系统设置维护。

安装包当前没有客户受信任的代码签名证书，因此 Windows 可能显示“未知发布者”。应先核验交付介质和 SHA-256；若客户制度要求可信发布者，必须由交付单位提供证书后重新签名。

## 覆盖升级

1. 备份 `%UserProfile%\Documents\温湿度校准数据` 和 `%LocalAppData%\IndustrialEquipmentCalibration`。
2. 退出程序，确认没有正在执行的正式采样。
3. 直接运行新版本安装包。固定安装目录和卸载标识使新文件覆盖旧版程序。
4. 启动后检查版本、系统设置、当前任务和历史记录。
5. 随机打开一条历史作业，确认冻结 CSV 及报告仍可读取。

升级不迁移或删除业务目录。不要把新版本安装到业务数据目录，也不要在程序运行时手工替换 DLL。

## 卸载

在 Windows“设置—应用—已安装的应用”中选择“温湿度巡检仪校准系统”，或从开始菜单选择卸载。卸载会删除程序、运行库、文档和快捷方式，但保留下列内容：

- `%UserProfile%\Documents\温湿度校准数据`；
- `%LocalAppData%\IndustrialEquipmentCalibration`。

如需彻底移交或销毁数据，应由客户按其数据制度另行备份、审批和删除，卸载程序不会代替该流程。

## 回退

1. 退出程序并备份当前数据。
2. 卸载当前程序，或直接运行经批准的旧版本安装包覆盖安装。
3. 启动旧版前保留新版本生成的数据副本。旧版可能无法识别较新的数据格式，不要让旧版覆盖新格式作业。
4. 源码回退以 Git 版本标签和提交为准；交付压缩包以 SHA-256 为准。

## 便携包

`UpperComInspectionInstrument2022-1.0.0-win-x64.zip` 是自包含应急包。完整解压后运行 EXE，不依赖目标电脑预装 .NET；不能只复制 EXE。便携运行与安装版共享同一用户的业务数据和本机配置。
