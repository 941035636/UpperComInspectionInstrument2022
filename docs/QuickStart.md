# 温湿度校准系统 V1.0 快速开始

## 运行前准备

1. 操作系统使用 64 位 Windows 10 或 Windows 11。
2. 安装巡检仪所用 USB 转串口驱动，在设备管理器确认对应 COM 口。
3. 关闭 Qt 旧程序、串口调试助手等可能占用同一 COM 口的软件。
4. 解压发布压缩包后，保持目录结构完整；不要只复制单个 EXE。
5. 业务数据默认保存在当前用户的 `文档\温湿度校准数据`，软件升级或删除程序目录不会自动删除该数据。

## 首次使用顺序

1. 打开 `UpperComInspectionInstrument2022.exe`。
2. 进入“系统设置”，维护实际使用的标准器名称、证书、有效期、量程、分辨力、不确定度、包含因子和修正值。
3. 进入“实时采集与校准”，先按 JJF 1101-2019 或 JJF 1376-2012 创建一个单工况任务。
4. 在工作台选择 COM 口、波特率和从站地址，先“连接巡检仪”，再“开始实时测量”。串口打开不等于设备已经响应，收到完整数据后状态才显示“设备已响应”。
5. 检查矩阵通道数、巡检仪屏幕示值和趋势。满足规范稳定条件并填写被校设备示值后，启动正式校准采样。
6. 正式样本达到计划组数后进入结果页，复核结果和不确定度，再生成 Excel、Word、PDF。
7. 从“历史记录”打开作业目录，确认任务、正式采样、原始通道、结果、不确定度和报告文件齐全。

## 通信异常处理

- 一次或两次超时：软件会按退避时间自动重试，不需要立即重复点击按钮。
- 连续三次失败：软件会停止请求并释放串口。检查设备电源、接线、COM 口和从站地址后重新连接。
- 串口访问被拒绝：关闭所有其他串口软件，拔插转换器后刷新端口。
- 软件上次异常退出：下次启动会把遗留的“采样中/记录中”目录标记为“已中断”，已经写入的数据不会删除。

## 数据与日志

- 正式作业：`文档\温湿度校准数据\JOB-...`；
- 普通实时测量：`文档\温湿度校准数据\实时测量记录\RT-...`；
- 用户操作记录：`文档\温湿度校准数据\操作记录.csv`；
- 运行日志：`文档\温湿度校准数据\运行日志\运行日志-yyyyMMdd.csv`。

以上 CSV 均可直接使用 Excel/WPS 打开。查看时不要在采集期间长期占用正在写入的 CSV；如需分析，建议先复制一份再打开。

## 当前版本边界

- 一次任务对应一个设定工况；多个设定点分别建立任务。
- 只支持 JJF 1101-2019 与 JJF 1376-2012 当前实现范围。
- 被校设备与委托信息可以不填，但正式出具报告前应按实验室制度补充并审核。
- 软件没有客户允差时不会自动给出“合格/不合格”结论；Word/PDF 初始状态为“待审核签发”。
- 当前压缩包是自包含便携发布候选，不是最终安装程序；正式客户安装包仍需完成安装、升级、卸载和目标电脑验证。
