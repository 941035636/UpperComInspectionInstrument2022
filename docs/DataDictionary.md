# V1.0.0 本地数据目录与字段字典

## 1. 存储原则

系统不使用数据库。业务数据均为带 UTF-8 BOM 的 CSV，可直接用 Excel/WPS 打开；Excel、Word 是由冻结 CSV 派生的交付文件。采集期间不要长时间用办公软件占用正在写入的 CSV，分析时应先复制副本。

## 2. 目录

| 位置 | 内容 | 卸载是否保留 |
| --- | --- | --- |
| `%UserProfile%\Documents\温湿度校准数据` | 正式作业、实时测量、操作记录、运行日志 | 保留 |
| `%LocalAppData%\IndustrialEquipmentCalibration` | 本地账户、记住密码、系统设置、当前任务状态 | 保留 |
| `%LocalAppData%\Programs\UpperComInspectionInstrument2022` | 程序、运行库、随附文档、卸载程序 | 删除 |

## 3. 正式作业目录

目录名为 `JOB-yyyyMMdd-HHmmss-fff_设备名称`。

| 文件 | 作用 | 关键字段 |
| --- | --- | --- |
| `作业摘要.csv` | 历史列表和恢复状态 | 数据格式版本、任务编号、系统校准日期、开始/结束时分秒、规范、校准类型、设备、设定值、测点数、计划/已存样本数、状态、状态说明、作业目录 |
| `任务信息.csv` | 创建任务时冻结的完整快照，采用“字段/值”两列 | 规范、设备/委托信息、校准点、布点、中心点、传感器、执行计划、现场条件、标准器及不确定度资料 |
| `正式采样.csv` | 每组一行的测点矩阵 | 样本序号、采样日期、精确到毫秒的采样时间（`HH:mm:ss.fff`）、有效/异常通道数、异常通道、固定三位小数的被校设备示值、温度1…N、湿度1…N；日期时间字段按办公软件友好文本保存，避免默认列宽显示 `#####` |
| `校准结果.csv` | 规范结果汇总 | 指标、数值、单位、说明 |
| `报告\校准原始记录.xlsx` | 按规范参考格式生成的 Excel 原始记录 | 从本作业冻结 CSV 生成 |
| `报告\校准证书.docx` | 按规范参考格式生成的 Word 报告 | 初始为待审核签发 |
| `报告\校准归档.pdf` | 固定版式的归档副本 | 作业信息、结果、不确定度摘要和签发状态 |

`状态`常见值：`采样中`、`已完成`、`已中断`、`保存异常`。`Missing` 通道会保留通道号和缺失原因，不用数值 0 代替。

## 4. 普通实时测量目录

目录为 `实时测量记录\RT-yyyyMMdd-HHmmss-fff_设备名称`。

| 文件 | 作用 | 关键字段 |
| --- | --- | --- |
| `实时测量摘要.csv` | 会话状态与通信配置 | 会话类型、起止时间、状态、已保存组数、串口、波特率、从站、周期、测点数、关联任务 |
| `实时测量.csv` | 每次完整设备响应一行 | 会话序号、采集序号、采集时间、有效/异常通道、温度1…N、湿度1…N |
| `实时测量原始通道.csv` | 每通道通信追溯 | 通道、值、单位、修正前值、修正值、有效性、状态、HEX、寄存器地址和值 |

## 5. 公共日志

- `操作记录.csv`：时间、操作、结果、对象编号、说明、相关路径、程序版本。
- `运行日志\运行日志-yyyyMMdd.csv`：时间、级别、分类、事件、详细信息、对象编号、相关路径、程序版本。

日志写入失败不会伪装为成功；界面会提示数据目录和失败原因。

## 6. 本机配置文件

| 文件 | 格式 | 说明 |
| --- | --- | --- |
| `users.json` | JSON | 用户名、显示名、PBKDF2-SHA256 盐值和摘要；不保存明文密码 |
| `remembered-login.json` | JSON + DPAPI 密文 | 仅当前 Windows 用户可解密；不应复制到其他电脑/用户 |
| `system-settings.json` | JSON | 实验室和标准器长期资料 |
| `calibration-task.json` | JSON | 当前任务状态；历史作业仍以各自 `任务信息.csv` 为准 |

这些 JSON 是程序配置，不是办公数据。不要用 Excel 修改；人工编辑损坏时应先备份，再由软件重新建立。

## 7. 数值和时间约定

- CSV 内部数值使用不依赖区域设置的小数点格式，并尽量保留计算精度。
- Excel/Word 交付结果显示到小数点后三位。
- 时间格式为 `yyyy-MM-dd HH:mm:ss.fff`。
- 报告生成始终读取作业目录冻结数据，不用后来修改的系统设置覆盖历史任务。
