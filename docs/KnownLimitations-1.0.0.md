# V1.0.0 已知限制与现场责任

1. 一次任务只处理一个设定工况。规范未要求的多工况自动编排已从 V1.0.0 范围移除。
2. 软件支持当前巡检仪协议中的 50 路温度和 10 路湿度；更换设备型号或固件后必须重新核对协议与寄存器映射。
3. 正式采样采用一轮完整温度块/湿度块响应形成一组数据；设备自身通道更新时间差异属于硬件特性，应在现场确认。
4. 无客户允差或设备技术指标时，软件不自动给出“合格/不合格”结论。
5. 被校设备与委托信息可暂不填写，但正式报告签发前必须按实验室制度补齐并复核。
6. 本地账户为单机便捷访问控制；忘记密码可直接重新注册，不具备联网找回、分级权限、电子签名和不可抵赖审计。
7. “记住密码”只对当前 Windows 用户有效，不等于自动登录，也不能跨电脑恢复。
8. 安装包未使用客户受信任的代码签名证书，可能显示“未知发布者”。
9. 按委托方本次要求，真实设备全流程/8 小时连续与故障测试，以及 Office/WPS 打印验收，不由本次开发工作执行；应在现场验收表中单独确认。
10. 软件计算与模板实现不能替代有资质人员对 JJF 1101-2019、JJF 1376-2012 的理解、原始记录复核和报告签发。
