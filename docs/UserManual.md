## 阅读说明

本说明书用于指导操作人员完成软件安装、账户登录、标准器资料维护、校准任务配置、巡检仪连接、实时测量、正式采样、结果复核、报告生成、历史查询和数据备份。软件把一次校准组织为连续的三步流程：任务配置、校准工作台、结果与报告。

本软件按照当前实现范围辅助执行 JJF 1101-2019 和 JJF 1376-2012 的工况校准。规范原文、实验室质量体系和被校设备技术要求仍是最终业务依据。软件计算结果不能替代校准员、核验员的专业判断和报告签发。

## 1 软件概述

### 1.1 主要用途

本软件连接温湿度巡检仪并读取最多 50 路温度、10 路湿度数据。系统根据任务中的测点数量选择参与显示和计算的通道，每轮完整设备响应形成一组实时数据。操作人员在实时趋势稳定后，可以不停止测量而直接启动正式校准采样。

软件提供以下功能：

- 按两项规范自动联动校准项目、容积分档、布点、中心点、稳定条件和采样计划；
- 读取巡检仪完整温度块和湿度块，并显示动态测点矩阵；
- 显示中心测点趋势、设定值、时间轴、温湿度双纵轴和异常通道信息；
- 自动保存普通实时测量数据和正式校准样本；
- 计算偏差、均匀度、波动度或稳定度、炉内最大温差和扩展不确定度；
- 从冻结的本地 CSV 生成 Excel 原始记录和 Word 校准报告；
- 查询已完成、已中断和保存异常的历史作业；
- 提供本地账户、记住密码、运行日志、操作记录和异常启动恢复。

### 1.2 当前支持范围

| 项目     | 支持范围                                            |
| ------ | ----------------------------------------------- |
| 环境试验设备 | JJF 1101-2019 温度参数或温湿度参数单工况校准                   |
| 箱式电阻炉  | JJF 1376-2012 温度参数单工况校准，最高 1300 ℃               |
| 温度传感器  | Pt100、Cu50、Cu100、K 型、S 型、E 型、J 型、T 型热电偶及其他自定义类型 |
| 温度通道   | 最多 50 路                                         |
| 湿度通道   | 最多 10 路                                         |
| 报告形式   | Excel 校准原始记录；Word 校准报告                          |
| 数据形式   | UTF-8 BOM CSV、JSON 配置、XLSX 和 DOCX               |

### 1.3 不属于自动结论的内容

软件在没有录入客户允差或被校设备技术指标时，只输出测量结果，不自动给出合格或不合格结论。Word 报告生成后处于待审核签发状态，必须由有资质人员复核任务信息、原始数据、结果、不确定度、布点图、偏离说明和签字页。

| 阶段  | 页面    | 操作                  | 形成的结果               |

## 3 安装与启动

### 3.1 运行环境

- 64 位 Windows 10 或 Windows 11；
- 可用的 RS232 串口或已安装驱动的 USB 转串口设备；
- 建议屏幕分辨率不低于 1366 × 768；
- 使用报告功能时，电脑应安装可打开 XLSX 和 DOCX 的 Microsoft Office 或 WPS；
- 使用串口前应关闭串口调试助手和其他可能占用同一 COM 口的软件。

### 3.2 安装程序

1. 找到 `UpperComInspectionInstrument2022-Setup-1.0.0.exe`。
2. 如交付介质同时提供 SHA-256 校验值，先核对文件哈希。
3. 双击安装程序并按向导完成安装。默认安装目录为 `%LocalAppData%\Programs\UpperComInspectionInstrument2022`，不需要管理员权限。
4. 从桌面或开始菜单启动温湿度巡检仪校准系统。
5. 安装包未使用客户受信任的代码签名证书时，Windows 可能显示未知发布者。确认安装包来自受控交付介质并核对哈希后再继续。

### 3.3 便携包

便携压缩包为 `UpperComInspectionInstrument2022-1.0.0-win-x64.zip`。必须完整解压后运行主程序，不能只复制一个 EXE。安装版和便携版使用同一个 Windows 用户的数据目录和本机配置目录。

### 3.4 覆盖升级和卸载

覆盖升级前应停止采集、退出程序并备份业务数据。直接运行新版本安装程序即可覆盖原安装目录。Windows 卸载只删除程序文件、快捷方式和卸载登记，不会删除业务数据、本地账户或系统设置。

## 4 本地账户与登录

### 4.1 首次注册

首次启动且电脑上没有账户时，系统自动显示注册页面。

1. 输入 2 至 32 位用户名。
2. 可填写显示名称。
3. 输入至少 8 位并同时包含字母和数字的密码。
4. 再次输入确认密码。
5. 点击创建账户，注册完成后返回登录页面，账户文件中不保存明文密码。

### 4.2 登录和记住密码

输入用户名、密码后点击登录。勾选记住密码后，系统使用当前 Windows 用户保存用户名和密码，下次启动只自动填充，不会自动点击登录。该密文不能复制到另一台电脑或另一个 Windows 用户使用。

### 4.3 忘记密码

点击忘记密码重新注册，系统切换到重新注册页面。重新注册成功后，原账户立即失效，旧的记住密码内容被清除。该操作不会删除校准数据、历史报告和系统设置。



### 4.4 注销

主窗口右上角显示当前用户。点击注销会返回登录页面。若正在采集，软件会提示停止采集；未完成的正式校准作业将按中断状态保存。

### 5.1 一级导航

### 5.2 页面切换规则

进入校准工作台后，切换到历史记录或系统设置不会停止后台实时采集，也不会清空实时矩阵和趋势。返回实时采集与校准时，系统复用当前工作台实例。

采集运行期间不能直接返回任务配置修改测点和通道。如果需要修改任务，应先暂停实时测量，再返回任务配置。保存的新任务参数会使旧矩阵失效，工作台按新测点数重新开始显示。

| 状态     | 含义                    | 操作建议               |

| 设备已响应  | 已收到完整合法响应             | 可以开始或继续实时测量        |

## 6 正式使用前准备

### 6.1 设备和连接检查

1. 确认巡检仪、传感器、被校设备和电脑供电正常。
2. 按实际布点完成温度和湿度通道接线，并记录通道与空间测点对应关系。
3. 在 Windows 设备管理器中确认 USB 转串口设备和 COM 口编号。
4. 关闭所有可能占用该串口的软件。
5. 核对巡检仪使用的波特率和从站地址。

### 6.2 标准器资料检查

正式采样前，系统会检查标准器名称、证书编号、有效期、分辨力、证书扩展不确定度 U、包含因子 k 和规范要求的能力字段。证书过期或参数不完整时，实时测量仍可继续，但正式校准按钮不可用。

### 6.3 数据目录检查

默认业务目录为 `%UserProfile%\Documents\温湿度校准数据`。确认磁盘空间充足并且当前 Windows 用户具有写入权限。采集期间不要用 Excel 或 WPS 长时间打开正在写入的 CSV 文件。

## 7 系统设置

### 7.1 进入方式和规范联动

推荐在任务配置页先选择 JJF 1101-2019 或 JJF 1376-2012，再点击维护标准器资料。系统设置页自动显示该规范需要的字段。

从左侧菜单直接进入系统设置时，如果当前正在任务配置页，系统优先使用页面上尚未保存的规范选择；其他情况下使用当前已保存任务的规范。

### 7.2 实验室与标准器身份

| 字段    | 是否必填 | 填写要求        |
| ----- | ---- | ----------- |
| 实验室名称 | 是    | 用于报告首页和签发信息 |
| 实验室地址 | 是    | 填写正式地址      |
| 标准器名称 | 是    | 与证书名称一致     |
| 证书编号  | 是    | 与当前有效证书一致   |
| 有效期至  | 是    | 不能早于当前日期    |
| 型号规格  | 否    | 按铭牌或证书填写    |
| 出厂编号  | 否    | 按铭牌或证书填写    |
| 校准机构  | 否    | 填写证书签发机构    |
| 机构地址  | 否    | 需要进入报告时填写   |

### 7.3 测量能力和规范固定值

温度量程、湿度量程和分辨力应按实际标准器证书或说明书填写。系统会根据任务规范自动显示并锁定下列固定要求：

| 规范            | 自动填入的只读内容                                    | 仍需人工维护的主要内容                   |
| ------------- | -------------------------------------------- | ----------------------------- |
| JJF 1101-2019 | 温度 MPE ±(0.15 ℃ + 0.002×∣t∣)；湿度 MPE ±2.0 %RH | 实际量程、温湿度分辨力、证书 U、k、稳定性变化和通道修正 |
| JJF 1376-2012 | 测温仪器 0.02 级；廉金属热电偶不低于 1 级；贵金属热电偶不低于 2 级      | 实际温度量程、温度分辨力、证书 U、k 和温度通道修正   |

JJF 1376 模式会隐藏湿度量程、湿度分辨力、湿度证书参数和湿度通道修正。

### 7.4 证书不确定度

扩展不确定度 U 和包含因子 k 必须来自实际标准器校准证书。不要把证书 U 直接当作软件最终结果的不确定度。软件还会结合重复性、分辨力以及相邻校准修正值最大变化等分量计算最终扩展不确定度。

修正值最大变化填写相邻两次校准证书中修正值变化的绝对最大值。没有可靠依据时，应由计量负责人确认后填写，不能随意使用零值降低不确定度。

### 7.5 通道修正

通道修正格式为 `通道号:修正值`，多项之间使用英文逗号。例如：

`1:0.02,2:-0.01,5:0.03`

温度最多填写 1 至 50 通道，湿度最多填写 1 至 10 通道。修正值正负号必须与证书一致。未填写的通道修正值按零处理，但操作人员应确认原始数据是否已经在巡检仪内部修正。

### 7.6 保存和任务快照

点击保存系统资料后，设置写入本机配置。新建或重新保存任务时，软件把当时的标准器资料复制为任务快照。之后修改系统设置不会自动改变已经建立的任务和历史作业。

如果工作台提示标准器资料已变化或无效，可点击同步维护标准器资料。同步只更新当前任务的标准器快照，不会中断实时测量或清空矩阵。

## 8 创建校准任务

### 8.1 校准依据

任务配置是流程第一步。依次选择校准规范、校准项目、容积分档和校准点方案。

| 字段     | JJF 1101-2019           | JJF 1376-2012      |
| ------ | ----------------------- | ------------------ |
| 校准项目   | 温度参数或温湿度参数              | 炉温参数               |
| 容积分界   | 工作空间小于等于或大于 2 m³        | 测温区小于等于或大于 0.15 m³ |
| 校准点方案  | 用户常用点；客户指定点             | 实际常用温度；客户指定温度      |
| 设定温度范围 | -80 ℃ 至 300 ℃           | 0 ℃ 至 1300 ℃       |
| 设定湿度范围 | 温湿度任务为 10 %RH 至 100 %RH | 不适用                |

客户指定校准点时，必须在偏离或自定义说明中记录客户要求。

### 8.2 被校设备与委托信息

该区域默认折叠，字段在连接、实时观察和计算阶段均为可选。正式出具报告前，应按实验室制度补齐委托单位、地址、校准地点、设备名称、制造厂、型号规格、出厂编号、校准日期、校准员和核验员。

不填写设备名称时，作业仍可建立，目录使用通用设备名称。报告签发前应补齐并复核这些信息。

### 8.3 JJF 1101 校准点与布点

| 容积        | 温度默认点数 | 温度中心点 | 湿度默认点数 | 湿度 O 点建议通道 |
| --------- | ------:| -----:| ------:| ----------:|
| 小于等于 2 m³ | 9      | 5     | 3      | CH3        |
| 大于 2 m³   | 15     | 15    | 4      | CH4        |

默认方案采用上层、中层、下层空间布点。各点距内壁通常为对应边长的十分之一，受风道影响时可调整，但不应超过 500 mm。湿度 A、B、C、O 与巡检仪通道的实际对应关系由接线决定，软件提供的是建议通道，必须现场核对。

布点方式包括规范默认空间布点、按实际工作位置调整和极端容积按需调整点数。选择可自定义方式后，温度点数、湿度点数和中心点可以修改，但必须填写布点说明。改变规范默认点数还必须填写偏离原因、依据和实际点数。

只有工作空间容积小于 0.05 m³ 或大于 50 m³ 时，才允许使用 JJF 1101 极端容积点数调整。此时必须完整填写工作区长、宽、高，软件会计算体积并校验容积分档。

点击查看布点图可以查看与容积分档对应的规范图示。数字表示温度测点，字母表示湿度测点，O 点位于中层几何中心。

### 8.4 JJF 1376 校准点与布点

| 测温区容积        | 默认温度点数 | 中心或监控点 | 默认布点特点            |
| ------------ | ------:| ------:| ----------------- |
| 小于等于 0.15 m³ | 5      | 3      | 一个几何中心监控点和四个规定端角点 |
| 大于 0.15 m³   | 9      | 9      | 八个端角点和一个监控点       |

JJF 1376 任务必须填写炉膛长度、宽度、高度和测温区长度、宽度、高度。软件按测温区尺寸计算容积，并核对所选 0.15 m³ 档位。

布点方式可以按生产厂或客户提供的工作区尺寸确定测温区，也可以按炉膛尺寸使用规范图 2，或按实际测温架和工作位置自定义。自定义点数和监控点时，必须逐点记录位置，并在偏离或自定义说明中说明不能采用规范 5 点或 9 点布置的原因。

监控点应按规范位置布置，并确认与控温热电偶测量端的关系。点击查看布点图可以查看当前 5 点或 9 点方案。

### 8.5 被校设备分辨力

被校温度分辨力和被校湿度分辨力是被校设备显示的最小变化量，用于设备档案和报告。它们不是系统设置中的标准器分辨力。两类分辨力应分别按铭牌、说明书或显示能力填写。

### 8.6 现场条件

两项规范的环境温度范围均为 15 ℃ 至 35 ℃，环境湿度不大于 85 %RH。JJF 1101 还要求气压为 80 kPa 至 106 kPa。软件会阻止超出范围的任务保存。

环境干扰确认框用于确认现场不存在强烈振动、腐蚀性气体、强气流、外部冷热源或其他影响校准的因素。未勾选时不能保存任务。

默认采用空载校准。选择负载时，必须填写负载情况，包括样品、装载位置和对气流或温场的影响。

### 8.7 稳定条件和正式采样计划

| 规范            | 默认稳定条件                                       | 默认正式样本  | 默认间隔  |
| ------------- | -------------------------------------------- | -------:| -----:|
| JJF 1101-2019 | 优先按设备说明书；无规定时到达设定值后等待 30 min，仍不稳定可延长至 60 min | 16 组    | 120 s |
| JJF 1376-2012 | 操作人员确认炉温达到校准温度并处于热稳定状态                       | 至少 20 组 | 180 s |

正式样本数和采样间隔允许按现场要求调整。改变 JJF 1101 的 16 组或 120 s 默认计划时，必须填写客户要求或设备运行情况说明。JJF 1376 样本数不得少于 20 组；改变 180 s 间隔，或使从第一组到最后一组的计划时长超过 60 min 时，必须填写偏离说明。

### 8.8 保存任务前的主要检查

系统会依次检查：

1. 规范、项目、容积分档和校准点方案已经选择；
2. 设定值落在规范适用范围内；
3. 传感器类型已经选择；
4. 测点数、中心点和被校设备分辨力有效；
5. 尺寸完整且计算体积与容积分档一致；
6. 自定义布点、客户指定点、负载或采样计划改变时已填写说明；
7. 环境条件符合范围且环境干扰已确认；
8. 标准器名称、证书、有效期、分辨力和不确定度资料完整有效。

点击保存并进入校准工作台后，任务参数和标准器资料形成快照。

## 9 校准工作台

### 9.1 页面组成

| 区域     | 内容                             |
| ------ | ------------------------------ |
| 顶部摘要   | 当前测量、近 5 组趋势预检、中心点、数据质量和最新采集时间 |
| 实时趋势   | 中心温度、湿度 O 点、任务设定值和最近 60 组时间趋势  |
| 测点数据矩阵 | 每行一组完整采集，每列一个任务测点              |
| 工作台控制  | 串口参数、文件记录、连接、实时测量、正式采样和稳定确认    |
| 当前任务   | 规范、设备、设定值、测点数、环境和采样计划摘要        |

### 9.2 串口参数

1. 点击刷新可用串口。
2. 选择与设备管理器一致的 COM 口。
3. 选择波特率。当前界面提供 115200 和 9600，必须与巡检仪设置一致。
4. 输入从站地址，通常为 1，按实际设备设置填写。
5. 输入读取周期，单位为毫秒。默认 2000 ms。读取周期是实时刷新频率，不是正式采样间隔。

### 9.3 连接巡检仪

点击连接巡检仪后，系统先独占打开串口。此时右上角可能显示串口已打开，等待设备响应。只有收到校验正确、长度完整的 Modbus 响应后，状态才变为设备已响应。

不要把串口已打开理解为通讯已经正常。如果长时间没有响应，应核对端口、波特率、从站地址、接线和设备供电。

再次点击连接按钮可以断开设备。断开前应先暂停测量，避免正在执行的请求被强制中止。

### 9.4 开始实时测量

设备响应后点击开始实时测量。软件读取完整温度块和湿度块，一轮完整响应形成一行矩阵。任务为纯温度时只保留温度通道；温湿度任务按配置的温度点数和湿度点数显示。

默认勾选自动保存实时记录。开始测量后，每组完整响应立即写入独立实时测量目录。可以点击打开目录查看保存位置。采集期间不要直接编辑正在写入的文件。

### 9.5 实时趋势

实时趋势显示任务中心温度和湿度 O 点的最近 60 组数据。温度使用左侧蓝色纵轴，湿度使用右侧绿色纵轴，横轴显示实际采集时间。虚线表示任务设定值。

把鼠标移到曲线上可以查看采集序号、毫秒级时间和中心点数值。无效或缺失数据会使折线中断，不会跨异常点直接连接。

趋势预检根据最近 5 组数据提示是否趋于稳定，仅用于辅助观察。该提示不能替代设备说明书、规范稳定条件和操作人员确认。

### 9.6 测点数据矩阵和数据质量

矩阵的前两列为采集序号和采集时间，后续列按任务自动生成温度 1 至 N、湿度 1 至 N。修改任务测点数后，矩阵、正式采样文件和计算输入会同时更新。

数据质量区域显示任务通道有效数和异常数。将鼠标停留在该区域可以查看异常通道、解析值、单位、范围原因、原始十六进制值和寄存器信息。

巡检仪湿度通道出现负数时，软件会保留负号并显示类似 `-1.25（异常）`。相对湿度有效范围按 0 至 100 %RH 判断，负湿度仅供通讯和探头诊断，不进入稳定趋势、正式样本和结果计算。湿度探头伴随温度同样只用于诊断，不作为额外校准通道。

### 9.7 正式校准启动条件

启动校准采样前必须同时满足：

- 已保存有效校准任务；
- 巡检仪正在返回有效实时数据；
- 任务要求的所有温湿度测点均有效；
- 任务中的标准器证书和能力快照完整且未过期；
- JJF 1376 外观和运行检查已经选择符合；
- 已按任务稳定依据完成等待或人工稳定确认；
- 已填写被校设备当前温度示值；温湿度任务还需填写当前湿度示值。

若任务采用 JJF 1101 默认等待，设备达到设定值后勾选对应确认框，系统从该时刻开始计时。其他稳定依据或 JJF 1376 任务由操作人员确认设备已稳定。

按钮不可用时，正式校准条件区域会列出尚未完成的事项。最近 5 组趋势即使显示稳定，也不能绕过证书、通道、外观和人工确认。

### 9.8 正式校准采样

点击启动校准采样后，实时测量继续运行。软件立即建立 `JOB` 作业目录，并按任务中的正式采样间隔记录完整样本。每次正式记录同时保存被校设备示值。

右侧显示已保存样本数和计划样本数。达到计划数量后，软件执行规范计算、写入校准结果、把作业状态更新为已完成，并启用查看结果与报告。

正式采样期间不要修改任务、关闭程序、拔出串口、断开巡检仪或占用 CSV 文件。通信故障时软件会有限重试；连续失败达到上限后停止请求、释放串口并保留中断记录。

### 9.9 暂停 清空和返回任务配置

- 暂停：等待当前巡检仪请求结束后停止实时测量，并正确关闭本次实时文件会话；未完成正式采样时作业标记为中断。
- 清空数据：只清空当前工作台内存中的快照、矩阵和趋势，不删除已经写入磁盘的实时记录或作业文件。
- 返回任务配置：采集运行时不可直接返回，应先暂停。修改并保存任务后，工作台按新任务重新建立矩阵。
- 切换页面：切换到历史记录或系统设置不停止正在运行的采集，返回校准作业后继续显示当前数据。

## 10 结果与报告

### 10.1 结果页面

正式样本达到计划数量后，结果页显示任务依据、现场环境、标准器快照和当前规范对应的结果。所有最终结果统一显示到小数点后三位，内部计算使用未提前舍入的完整精度。

### 10.2 JJF 1101 结果口径

| 结果     | 软件计算口径                              |
| ------ | ----------------------------------- |
| 温度上偏差  | 所有正式样本中的最大温度减去设定温度                  |
| 温度下偏差  | 所有正式样本中的最小温度减去设定温度                  |
| 温度均匀度  | 每组最大温度与最小温度之差的算术平均                  |
| 温度波动度  | 各测点在规定时间内极差一半的最大值                   |
| 湿度偏差   | 最大或最小正式湿度分别减去设定湿度                   |
| 湿度均匀度  | 每组最大湿度与最小湿度之差的算术平均                  |
| 湿度波动度  | 各湿度测点极差一半的最大值                       |
| 扩展不确定度 | 重复性、标准器分辨力、证书 U 和稳定性变化等分量合成后乘包含因子 k |

### 10.3 JJF 1376 结果口径

| 结果        | 软件计算口径                         |
| --------- | ------------------------------ |
| 炉温均匀度     | 各空间点多次采样平均值相对中心监控点平均值的上偏差和下偏差  |
| 炉温稳定度     | 中心点最大值和最小值相对中心点平均值的上偏差和下偏差     |
| 炉温偏差      | 各点平均值中的最高值和最低值分别减去标称温度         |
| 炉内最大温差    | 每组所有测点最大值与最小值之差中的最大值           |
| 均匀度扩展不确定度 | 极值点与中心点的重复测量平均值分量和证书修正分量合成后乘 k |

同一测点与自身相减时，不确定度贡献按完全相关抵消处理。软件不把规范中的参考技术指标直接作为被校设备合格判据。

### 10.4 生成 Excel 原始记录

点击生成原始记录 Excel。首次点击时，软件从当前作业目录内冻结的 CSV 生成 `报告\校准原始记录.xlsx`，随后调用系统默认办公软件打开。文件已经存在时，按钮直接打开现有文件。

Excel 采用与当前规范相对应的原始记录结构，包含规范记录页、正式采样和任务快照。JJF 1101 文件包含传感器布点示意；JJF 1376 文件包含炉膛、测温区尺寸和对应校准结果。

### 10.5 生成 Word 校准报告

点击生成校准报告 Word。首次点击时生成 `报告\校准证书.docx`，随后用默认办公软件打开。报告按 JJF 1101 或 JJF 1376 参考结构组织，声明和签发信息位于文档末尾。

报告生成后应重点复核：委托和设备信息、规范、校准地点、设定值、环境条件、标准器证书、样本数、计算结果、不确定度、布点图、偏离说明、校准员、核验员、声明和签发日期。

### 10.6 报告数据来源

Excel 和 Word 只读取当前作业目录中的冻结 CSV，不读取后来修改的系统设置。因此历史任务可以重复生成相同业务内容，系统设置变化不会静默覆盖历史报告依据。

## 11 历史记录

### 11.1 查询作业

历史记录页支持按任务编号、设备名称或证书编号关键字查询，并可按规范和状态筛选。列表显示任务时间、任务编号、规范、被校设备、校准项目、样本进度、状态、Excel 状态、Word 状态和状态说明。

### 11.2 常用操作

选中一条作业后可以：

- 打开作业目录；
- 生成或打开原始记录 Excel；
- 生成或打开校准报告 Word。

双击列表行也可以打开作业目录。历史页没有多余的逐项 CSV 导出按钮，内部 CSV 由系统自动管理。

### 11.3 历史状态处理

已完成表示计划样本、结果和作业摘要已完整保存。已中断表示正式样本不足，已有数据保留但不能直接作为完整校准结果签发。保存异常表示本地文件没有完整写入，应先保留目录并检查日志、磁盘和权限。

## 12 本地数据和文件结构

### 12.1 存储原则

系统不使用数据库。业务数据采用可由 Excel 或 WPS 打开的 UTF-8 BOM CSV。Excel 和 Word 是从冻结 CSV 派生的交付文件。账户和配置使用 JSON，不能用 Excel 修改。

### 12.2 主要目录

| 路径                                                         | 内容                  | 卸载后是否保留 |
| ---------------------------------------------------------- | ------------------- | ------- |
| `%UserProfile%\Documents\温湿度校准数据`                          | 正式作业、实时测量、操作记录和运行日志 | 保留      |
| `%LocalAppData%\IndustrialEquipmentCalibration`            | 本地账户、记住密码、系统设置和当前任务 | 保留      |
| `%LocalAppData%\Programs\UpperComInspectionInstrument2022` | 程序、运行库和随附文档         | 删除      |

### 12.3 正式作业目录

目录名称为 `JOB-yyyyMMdd-HHmmss-fff_设备名称`。

| 文件             | 作用                     |
| -------------- | ---------------------- |
| 作业摘要.csv       | 历史列表、任务编号、状态、样本进度和作业路径 |
| 任务信息.csv       | 任务配置和标准器资料的冻结快照        |
| 正式采样.csv       | 每组一行的正式测点矩阵            |
| 校准结果.csv       | 当前规范的最终结果，显示值保留三位小数    |
| 报告\校准原始记录.xlsx | Excel 原始记录             |
| 报告\校准证书.docx   | Word 校准报告              |

正式作业目录不再生成单独的不确定度分量 CSV、正式采样原始通道 CSV 或内部追溯数据文件夹。最终扩展不确定度仍保存在校准结果和报告中。

### 12.4 普通实时测量目录

目录名称为 `实时测量记录\RT-yyyyMMdd-HHmmss-fff_设备名称`。

| 文件           | 作用                       |
| ------------ | ------------------------ |
| 实时测量摘要.csv   | 会话时间、状态、串口配置、测点数和保存组数    |
| 实时测量.csv     | 每轮完整响应形成的一行实时矩阵          |
| 实时测量原始通道.csv | 原始值、修正值、有效性、十六进制数据和寄存器信息 |

### 12.5 日志

`操作记录.csv` 记录登录、任务保存、报告生成等重要操作。`运行日志\运行日志-yyyyMMdd.csv` 记录通讯、存储和程序异常。排查故障时应先保留日志和对应作业目录。

## 13 数据备份与恢复

### 13.1 备份

1. 暂停实时测量和正式采样并正常退出软件。
2. 确认任务管理器中没有主程序进程。
3. 备份 `%UserProfile%\Documents\温湿度校准数据`。
4. 建议同时备份 `%LocalAppData%\IndustrialEquipmentCalibration`。
5. 对备份压缩包计算 SHA-256，并登记文件名、大小、哈希、时间和操作人员。
6. 抽查备份可以打开，且正式作业至少包含四个业务 CSV 和报告目录。

不要只备份 Excel 和 Word。任务信息、正式采样和校准结果 CSV 是重新生成报告的基础。

### 13.2 恢复

1. 退出软件并把当前数据目录改名保留。
2. 将备份恢复到原路径，保持目录层级和文件名不变。
3. 跨电脑恢复时不要复制 `remembered-login.json`，因为该密文只对原 Windows 用户有效。
4. 启动软件，检查历史记录数量和状态。
5. 随机打开一条 JJF 1101 和一条 JJF 1376 作业，并从冻结 CSV 生成 Excel 和 Word。
6. 验证完成前不要删除恢复前的目录副本。

## 14 常见故障处理

| 现象            | 可能原因                     | 处理方法                           |
| ------------- | ------------------------ | ------------------------------ |
| COM 口拒绝访问     | 端口被 Qt、串口助手或残留进程占用       | 关闭其他串口程序，结束残留进程，拔插转换器后刷新串口     |
| 串口已打开但设备无响应   | 波特率、从站地址、接线或供电错误         | 逐项核对设备设置，避免连续快速点击连接            |
| 读取超时          | 通讯波动或响应不完整               | 等待软件自动重试；连续失败后检查设备并重新连接        |
| 个别通道为 0 或缺失   | 接线、寄存器映射、点数或传感器异常        | 对照巡检仪屏幕和任务点数，查看数据质量悬停明细和原始通道文件 |
| 湿度显示负数        | 设备实际返回负值或探头异常            | 核对巡检仪屏幕、原始 HEX 和探头；负值不会进入正式计算  |
| 矩阵列数不正确       | 任务测点数未保存或旧任务仍在工作台        | 暂停测量，返回任务配置保存正确点数，再重新开始        |
| 无法启动正式校准      | 通道无效、未稳定、证书过期、外观未确认或示值未填 | 阅读正式校准条件区域列出的每一项并逐项处理          |
| 标准器资料不完整      | 系统设置缺项或任务快照过期            | 点击同步维护标准器资料，保存后返回工作台再次同步       |
| 报告按钮不可用       | 正式样本不足或结果计算失败            | 完成计划样本并检查缺失通道和作业状态             |
| 报告无法打开        | 文件未生成或办公软件关联异常           | 从历史记录重新选择作业，确认文件存在并检查默认程序关联    |
| 保存异常          | 磁盘已满、目录无权限或 CSV 被占用      | 关闭占用文件的软件，释放空间，保留日志后重试         |
| 异常退出后作业仍显示采样中 | 上次未正常关闭                  | 重新启动软件，系统会把遗留作业恢复为已中断          |
| 记住密码失效        | 更换电脑、Windows 用户或加密文件损坏   | 手工输入密码；必要时删除记住密码文件或重新注册        |

## 15 安全和使用边界

1. 本地账户不具备联网找回、分级权限、电子签名和不可抵赖审计能力。
2. 忘记密码可直接重新注册，只适合受控单机。
3. 一次任务只对应一个设定工况。多个温度或湿度工况应分别建立任务。
4. 更换巡检仪型号或固件后，必须重新核对 Modbus 协议和寄存器映射。
5. 正式样本以一轮完整设备响应为一组。设备内部各通道刷新时差属于硬件特性，应在现场验收中确认。
6. 软件结果不能替代规范原文、客户技术要求和有资质人员签发。
7. 未录入客户允差时，软件不会自动输出合格或不合格。
8. 安装程序没有客户受信任签名时，正式部署应由交付单位按客户制度签名或完成受控放行。

## 附录 C 术语

| 术语     | 说明                                      |
| ------ | --------------------------------------- |
| MPE    | 最大允许误差。系统设置中显示的是规范对测量标准的要求，不是被校设备自动判定限值 |
| U      | 扩展不确定度，通常由标准器证书给出或由软件评定结果输出             |
| k      | 包含因子，用于由合成标准不确定度得到扩展不确定度                |
| 中心点    | 环境设备工作空间几何中心附近的温度测点                     |
| 湿度 O 点 | 环境设备中层几何中心的湿度测点，具体巡检仪通道由实际接线决定          |
| 监控点    | 箱式电阻炉用于稳定度和均匀度计算的中心或规定监控测点              |
| 任务快照   | 保存任务时冻结的规范、现场条件和标准器资料副本                 |
| 完整响应   | 一轮协议请求返回并通过校验的完整温度块或温湿度数据块              |
| 实时记录   | 用于观察和设备诊断的连续数据，不等同于正式校准样本               |
| 正式样本   | 在满足稳定条件后，按任务计划间隔保存并参与结果计算的数据组           |
