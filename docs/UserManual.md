# 温湿度巡检仪校准系统 V1.0.0 用户手册

## 1. 软件用途

本软件用于连接温湿度巡检仪，完成实时观察、正式采样、结果计算、本地归档以及 Excel 原始记录和 Word 校准报告生成。当前业务范围为：

- JJF 1101-2019 环境试验设备温度、湿度参数单工况校准；
- JJF 1376-2012 箱式电阻炉单工况校准；
- 50 路温度、10 路湿度 Modbus RTU 数据读取，并按任务测点数选择所需通道；
- 所有业务数据以本地 CSV 文件保存，不使用数据库。

软件给出的计算结果用于记录和复核。正式报告必须由校准员、核验员按实验室质量制度审核签发。

## 2. 安装与首次启动

1. 使用 64 位 Windows 10 或 Windows 11，安装 USB 转串口设备驱动。
2. 运行 `UpperComInspectionInstrument2022-Setup-1.0.0.exe`。安装位置默认为 `%LocalAppData%\Programs\UpperComInspectionInstrument2022`，不需要管理员权限。
3. 从桌面或开始菜单启动“温湿度巡检仪校准系统”。
4. 首次运行进入本地账户注册：用户名 2～32 位；密码不少于 8 位且同时包含字母和数字。
5. 登录时可勾选“记住密码”。密码使用当前 Windows 用户的 DPAPI 密钥加密保存，不会自动登录。

忘记密码时选择“忘记密码？重新注册”。确认后直接创建新账户，旧账户立即失效，记住的密码被清除；校准数据、历史报告和系统设置不会删除。该方式不验证原账户身份，仅适合受控的单机环境。

## 3. 一级功能结构

- 校准作业：任务配置、实时测量、稳定观察和正式采样在同一连续流程内完成。
- 历史记录：查找已完成或中断作业，生成/打开 Excel 原始记录和 Word 校准报告。
- 系统设置：维护实验室和标准器长期资料，不填写本次被校设备和委托信息。

任务配置完成并进入工作台后，即使切换到历史记录或系统设置，实时采集状态和工作台数据仍由当前会话保持；返回“校准作业”可继续查看。

## 4. 系统设置

首次正式使用前维护以下资料：实验室名称与地址、标准器名称、型号、编号、证书编号、有效期、溯源机构、量程、分辨力、准确度说明、扩展不确定度及包含因子、各通道证书修正值。

系统设置是长期资料。创建任务时会复制为任务快照，之后修改系统设置不会静默改变已建立任务或历史报告。证书过期、名称/编号缺失时工作台会阻止正式采样，并指出需补充的字段。

通道修正值格式为 `通道号:修正值`，多项用逗号分隔，例如 `1:0.02,2:-0.01`。必须按实际证书和接线顺序维护。

## 5. 创建校准任务

### 5.1 校准依据

选择 JJF 1101-2019 或 JJF 1376-2012。校准项目、布点方案、测点数、中心点、正式样本数和采样间隔会随规范切换。

### 5.2 被校设备与委托信息

这些字段不影响连接、实时观察和计算，可以暂不填写；正式出具报告前应补齐实验室制度要求的名称、型号、编号、制造单位、委托单位、地点、日期及人员信息。

### 5.3 校准点与布点

- 设定温度、设定湿度是本次单工况任务值，不是写死常量。
- JJF 1101 的温度/湿度测点数和中心点由布点方案给出，选择“按实际工作位置调整”时允许在规范边界内自定义。
- JJF 1376 的温度测点数、中心点同样随布点模式联动；需要时可查看内置布点图。
- 修改测点数后，工作台矩阵列数、正式采样文件列数和计算输入同时更新。

### 5.4 现场条件与执行计划

录入环境温度、湿度、气压、负载状态、外观/运行检查和偏离说明。正式样本数与正式采样间隔可在规范下限约束内自定义；界面校验不通过时不能保存任务。

保存后进入工作台。工作台采用任务快照，避免采集中途修改关键规则导致前后数据口径不一致。

## 6. 实时测量与正式采样

1. 选择 COM 口、波特率、从站地址和读取周期。
2. 关闭 Qt 旧程序、串口助手等占用同一端口的软件。
3. 点击“连接巡检仪”。“串口已打开”只表示端口占用成功；收到完整合法响应后才显示“设备已响应”。
4. 点击“开始实时测量”。软件按协议读取完整温度块和湿度块，一轮完整响应形成一组矩阵数据；不会把轮询单通道误当成同一时刻的整组正式样本。
5. 核对测点矩阵、巡检仪屏幕值、异常通道和趋势。矩阵只显示任务需要的温度、湿度通道。
6. 达到规范稳定条件后，由操作人员勾选稳定确认并填写被校设备示值。
7. 点击“启动校准采样”。正式样本按任务间隔自动记录；达到计划组数后自动计算并进入结果页。

普通实时测量启动后即建立独立 CSV 会话。正式采样另建校准作业目录，二者不会混在一起。清空工作台只清除内存显示，不删除已落盘文件。

## 7. 结果与报告

结果页展示偏差、均匀度、波动度/稳定度、最大温差和扩展不确定度等与当前规范相对应的项目，计算结果统一显示到小数点后三位。

- “生成/更新 Excel”：生成符合规范参考记录结构的原始记录工作簿，包含任务信息、正式样本、原始通道和不确定度依据。
- “生成/更新 Word”：生成校准报告，初始状态为“待审核签发”；声明与签发信息位于报告末尾。

报告生成只读取作业目录内冻结的 CSV，不读取当前系统设置，因此历史任务可重复生成同一业务内容。生成后必须复核任务信息、原始值、修正值、结果、布点图、签字和分页。

## 8. 历史记录

可按关键词、规范和状态查询。选中一条作业后只保留三类常用动作：打开作业目录、生成/打开 Excel 原始记录、生成/打开 Word 校准报告。内部 CSV 是系统追溯文件，无需逐个导出。

状态“已中断”表示程序关闭、通信故障或操作员停止时未完成计划样本；已有数据仍保留，但不能作为完整校准结果直接签发。

## 9. 数据、备份和恢复

业务数据默认位于 `%UserProfile%\Documents\温湿度校准数据`；账户和长期设置位于 `%LocalAppData%\IndustrialEquipmentCalibration`。升级和卸载均不会删除这些目录。

备份前退出软件，把上述目录复制到受控介质。恢复时先保留当前目录副本，再将备份复制回原位置。跨电脑恢复时不要复制 `remembered-login.json`，因为其密文只对原 Windows 用户有效。详细操作见 `BackupAndRestore.md`。

## 10. 常见故障

- COM 口拒绝访问：关闭其他串口程序，确认任务管理器中没有残留进程，拔插转换器后刷新端口。
- 一直等待设备响应：核对波特率、从站地址、接线和供电；不要连续快速点击连接按钮。
- 个别通道为空或异常：核对任务测点数、实际接线、巡检仪显示和协议寄存器；原始通道 CSV 会保留 HEX 与寄存器值。
- 无法启动正式采样：按右侧提示补齐有效标准器资料、达到稳定条件、确认外观/运行状态并填写必要示值。
- 报告无法打开：先确认文件已经生成，再检查默认办公软件关联；作业目录中的 CSV 不受影响。
- 异常退出：重新启动后，遗留的“采样中/记录中”会自动标记为“已中断”。

## 11. 安全与责任边界

本地登录不是联网身份系统，不具备邮件找回、组织权限、电子签名或不可抵赖审计。客户应通过 Windows 账户、电脑物理管理、文件夹权限和备份制度保护数据。软件未签名时 Windows 可能显示“未知发布者”；生产签名需由交付单位提供可信代码签名证书。
